# Responsive
## PC
思考と構造のためのデバイス
・座っている
・両手が空いている
・視線移動が自由
⇒情報を「比較・検討」する

情報構造：最優先、一番華やかな舞台
同時に複数情報を見せてOK
マウス前提
画面端でも問題なし
・見せ方：最もリッチ
余白広め
背景演出OK
アニメーションも許容

## タブレット
「PCの縮小版」でも
「スマホの拡大版」でもない
⇒持ち替えが発生する端末

1. 情報構造はPCのまま
2. 操作位置はスマホ寄り
3. 見せ方は中庸

## スマホ
・片手
・親指操作
・立っている／移動中
⇒情報を「選別」している

1. 情報構造：削る
重要なものだけ
一度に1テーマ
深さより即時性
2. 操作位置：最重要
画面下〜中央
押しやすさ最優先
操作を迷わせない
3. 見せ方：最短距離
余白は最低限
装飾は意味があるものだけ
アニメーションはほぼ不要
⇒スマホは「決断させる装置」

CSSだけで調整するのが正解。
